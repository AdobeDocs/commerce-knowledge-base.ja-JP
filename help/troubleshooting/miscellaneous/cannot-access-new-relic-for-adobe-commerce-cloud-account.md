# Adobe Commerce Cloud プロジェクトの[!DNL New Relic]にアクセスできません

この記事では、Adobe Commerce クラウドプロジェクトに追加されているにもかかわらず[!DNL New Relic]にアクセスできない場合の解決策を紹介します。

## 影響を受ける製品とバージョン

* クラウド インフラストラクチャ上のAdobe Commerceはすべて[&#x200B; サポートされているバージョン &#x200B;](https://www.adobe.com/content/dam/cc/en/legal/terms/enterprise/pdfs/Adobe-Commerce-Software-Lifecycle-Policy.pdf)

## イシュー

クラウドプロジェクトに追加されているにもかかわらず、そのプロジェクトの[!DNL New Relic] アカウントにアクセスできません。

## 原因

クラウドプロジェクトに追加しても、自動的に[!DNL New Relic] アクセス権が付与されません。

## Solution

New Relic アカウントの所有者に連絡し、[!DNL New Relic]のアカウントにユーザーを追加するように依頼します。
