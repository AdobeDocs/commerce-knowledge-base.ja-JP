# 品質パッチツールがリリースされました：品質パッチをセルフサービスで提供する新しいツール

Adobeでは、インストール済みのバージョンのAdobe Commerce（オンプレミスおよびクラウドインフラストラクチャの両方）またはMagento Open Sourceで利用可能な高品質パッチに関する一般的な情報を適用、元に戻し、表示できるツールであるQuality Patches Tool for general availabilityをリリースしました。

このツールは、より迅速なセルフサービス方式の問題解決を提供し、Adobe Commerceで発生する可能性のある問題に対して、Adobe Commerce サポートが提案したパッチを簡単に適用できます。

>[!NOTE]
>
>このツールを使用して、必要に応じて必要な品質修正をケースバイケースで行い、Adobe CommerceとMagento Open Sourceのコードを長期的に管理する方法としてではなく、必要に応じて行う必要があります。 最新バージョンのAdobe CommerceまたはMagento Open Sourceへのアップグレードは、引き続き品質問題の解決に最適な方法であり、優先する必要があります。

## 品質パッチツールの取得と使用

このツールは、コンポーザーパッケージとして使用できます。 Adobe Commerce on cloud infrastructureの場合、パッケージはECE-Tools パッケージに含まれています。

ツールをインストールしたら、利用可能なパッチを確認し、いつでも適用または元に戻すことができます。

詳しくは、次の開発者向けドキュメントを参照してください。

* [品質パッチツールで使用可能なパッチ](https://experienceleague.adobe.com/tools/commerce-quality-patches/index.html)
* [品質パッチツールのリリースノート](https://experienceleague.adobe.com/en/docs/commerce-operations/tools/quality-patches-tool/release-notes)
